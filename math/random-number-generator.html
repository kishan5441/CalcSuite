About Random Number Generation

This calculator uses the browser's Web Crypto API (crypto.getRandomValues) to generate cryptographically secure random values. Integer generation uses rejection sampling to avoid modulo bias. This is substantially stronger than ordinary Math.random() for unpredictable random values, but it is not a physical true-random-number generator based on hardware entropy measurements.
